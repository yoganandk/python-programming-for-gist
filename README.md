## Course Description
This course introduces Python programming fundamentals for Geographic Information Science and Technology (GIST) with an emphasis on geospatial problem-solving and modern AI-supported learning. Students develop core programming skills, including data types and variables, control structures, functions, data structures, file handling, error management, and object-oriented programming, while applying these concepts to geographic data analysis and workflow automation. AI is integrated throughout the course as a key learning accelerator and support tool, enhancing code comprehension, improving debugging efficiency, and strengthening conceptual understanding of programming principles. Students gain experience using AI-enabled resources to reinforce foundational skills and to develop effective, contemporary coding practices. The course also introduces essential Python libraries used in geospatial analytics and automation. Through coding demonstrations, structured reference materials, AI-supported exercises, and quizzes, students build proficiency and confidence in applying computational methods to geospatial applications.
